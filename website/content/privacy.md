## In short

spec-tacular.app is a static website: the landing page and the documentation of spec-tacular. There are no user accounts, no forms and no cookies. A cookieless statistic counts page views (see [Page statistics](#page-statistics)); it stores nothing on your device and builds no profiles.

Personal data is handled in line with the Swiss Federal Act on Data Protection (FADP) and, where it applies, the EU General Data Protection Regulation (GDPR), and only as far as running the site needs it.

## Server logs

When you open a page, the hosting provider records technical access data: IP address, date and time, the page requested, the amount of data sent, the referrer, browser type and operating system. This is needed to run the site securely. The data is deleted when the hosting provider's retention period ends and is not combined with other data.

Legal basis: legitimate interest in running the site securely (Art. 6(1)(f) GDPR).

## Fonts

The font (JetBrains Mono) is served by this site itself. There is no connection to Google Fonts or any other font service.

## Stored on your device

Your choice of light or dark mode is kept in your browser's local storage. It never leaves your device.

## Page statistics

To see which pages are read, this site uses [Plausible Analytics](https://plausible.io/privacy-focused-web-analytics). It runs on its own instance at stats.marius-hoegger.ch, hosted by Infomaniak in Switzerland, so the data stays in Swiss data centres and no analytics company receives it.

Plausible sets no cookies and stores nothing on your device. Per page view it records the page, the referrer, the approximate location (country, region, city), device type, browser and operating system. Your IP address is not stored: it is used only, together with the browser and a daily changing random value, to count unique visitors for one day, and that value is discarded every day. No profiles are built, visits are not linked across websites, and the data is not passed on or used for advertising.

Legal basis: legitimate interest in privacy-friendly page statistics (Art. 6(1)(f) GDPR).

To stop the statistics anyway, a content blocker such as uBlock Origin keeps the script from loading.

## Installing spec-tacular

The install script at `spec-tacular.app/install.sh` is a static file served like any page. It downloads spec-tacular from GitHub Releases, so that download is handled by GitHub under [GitHub's privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). spec-tacular itself sends nothing to this site or to its author.
