On this page you install the OpenSpec CLI and spec-tacular, and check that your agent is ready. When you are done, `spec-tacular --version` prints a version.

## Prerequisites

- **Linux or macOS**, on x64 or arm64. There is no Windows build. On other systems you can [build from source](#build-from-source).
- **The OpenSpec CLI.** spec-tacular drives it, so you install it separately. This needs npm:

  ```bash
  npm i -g @fission-ai/openspec
  ```

- **An agent, installed and signed in.** Either [Claude Code](https://docs.anthropic.com/en/docs/claude-code) or [opencode](https://opencode.ai). spec-tacular starts it for you to draft artifacts, answer setup questions and implement tasks. Claude Code is the default. To use opencode, start spec-tacular with `--driver opencode` each time.

spec-tacular itself is a single binary. It needs no Bun or Node of its own.

## Install spec-tacular

::warning
**Early access.** The spec-tacular repository is private for now. The install command below works only if your GitHub account has access to it. There is no public install path yet.
::

The install script picks the build for your OS and CPU, checks it against the release's `SHA256SUMS`, and installs `spec-tacular` to `~/.local/bin`.

While the repository is private, fetch the script with the [GitHub CLI](https://cli.github.com). Sign `gh` in first (`gh auth login`) with an account that has access:

```bash
gh api repos/wingfold-ai/spec-tacular/contents/install.sh -H 'Accept: application/vnd.github.raw' | sh
```

Once the repository is public, you will be able to install without `gh`. This command does not work until the repository is public:

```bash
curl -fsSL https://spec-tacular.app/install.sh | sh
```

::caution
The npm package `@spec-tacular/cli` is only a name reservation for now. Do not install spec-tacular from npm yet.
::

### If spec-tacular is not on your PATH

If the install directory is not on your `PATH`, the script ends with this note:

::terminal-block
---
title: install.sh
lines: |
  note: /home/you/.local/bin is not on your PATH; add it to run `spec-tacular` by name.
---
::

Add the directory to your `PATH` in your shell's startup file: `~/.bashrc` for bash, `~/.zshrc` for zsh (the default shell on macOS). Then open a new terminal.

::code-group
```bash [bash]
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
```
```bash [zsh]
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
```
::

If `openspec` is not on your `PATH` either, the script also reminds you to install it.

### Options

Set these environment variables for the `sh` at the end of the pipe:

| Variable | Effect |
| --- | --- |
| `SPECTACULAR_VERSION` | A release tag such as `v0.1.0`. Default: the latest release. |
| `SPECTACULAR_INSTALL_DIR` | Where the binary goes. Default: `~/.local/bin`. |

```bash
gh api repos/wingfold-ai/spec-tacular/contents/install.sh -H 'Accept: application/vnd.github.raw' | SPECTACULAR_VERSION=v0.1.0 sh
```

::note
Releases up to v0.3.0 named the command, and their archives, `spectacular`. If an old `spectacular` is in the install directory, the script removes it when it installs `spec-tacular`.
::

### Install by hand

Download `spec-tacular-<version>-<os>-<arch>.tar.gz` and `SHA256SUMS` from a release, check the archive, and copy the binary. This also needs access to the repository. For Linux x64:

```bash
gh release download -R wingfold-ai/spec-tacular -p 'spec-tacular-*-linux-x64.tar.gz' -p SHA256SUMS
sha256sum --check --ignore-missing SHA256SUMS
tar -xzf spec-tacular-*-linux-x64.tar.gz
install spec-tacular-*-linux-x64/spec-tacular ~/.local/bin/
```

On macOS, check the archive with `shasum -a 256 --check --ignore-missing SHA256SUMS` instead.

## Verify

```bash
spec-tacular --version
```

It prints `spec-tacular` followed by the installed version. Then check that OpenSpec is on your `PATH`:

```bash
openspec --version
```

Finally, start `claude` (or `opencode`) once in a terminal and confirm you are signed in. Most of the agent work spec-tacular starts runs in the background, without a terminal window of its own, so sign in beforehand.

## Update

Run the install command again. It replaces the binary with the latest release, or with the release you set in `SPECTACULAR_VERSION`. A running spec-tacular is not overwritten in place.

## Uninstall

Delete the binary:

```bash
rm ~/.local/bin/spec-tacular
```

If you installed to another directory with `SPECTACULAR_INSTALL_DIR`, delete it from there. This does not touch your projects: the files spec-tacular wrote into a project stay there. See [Files](/docs/reference/files).

## Build from source

You need [Bun](https://bun.sh) and a clone of the repository, which also needs access while it is private. In the clone, run:

```bash
bun install && bun run build
```

This writes the binary to `dist/spec-tacular`. Copy it to a directory on your `PATH`.

## MCP servers

MCP (Model Context Protocol) servers are the extra tools you may have connected to Claude Code, such as a ticket tracker or a cloud drive. By default, the agents spec-tacular starts load your Claude Code MCP servers and may call their tools without asking you. To change that:

| Variable | Effect |
| --- | --- |
| `SPECTACULAR_NO_MCP=1` | Start no MCP servers. Sessions also start faster. |
| `SPECTACULAR_MCP_DENY` | MCP servers the agents may not call, separated by spaces or commas and matched by name, for example `godaddy google_drive`. |

See [Configuration](/docs/reference/configuration) for every variable.
